\section{Versioned local inputs}\label{sec:imports}
In this table C denotes the classical source~\cite{DMNoise1D2026}, version~2.1.0, doi:10.5281/zenodo.24408026; M denotes the quantum-memory source~\cite{DMMemory2026}, version~3.1.0, doi:10.5281/zenodo.24431439. The listed statements and indicated proof passages are present in these versions with the hypotheses and conclusions used here. The classical statements are applied to the fixed-rate homogeneous never-halting family, not the searching single-rule noise diagram. The scalar-layout change is justified by M, Lemma~13.6. Expanded compiler lists and the additional raw-read count are proved in this paper; they are not asserted to be verbatim conclusions about the older hardware.
